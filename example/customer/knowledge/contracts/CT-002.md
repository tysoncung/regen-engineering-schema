## Scenario: the first address becomes the default

Given a customer with no addresses
When the customer adds an address
Then that address is the default shipping address

## Scenario: deleting the default promotes the most recently used

Given a customer with three addresses, one of them the default
And one of the other two was used more recently than the third
When the customer deletes the default address
Then the most recently used remaining address becomes the default
And the customer has two addresses

## Scenario: deleting the default when none has been used

Given a customer with two addresses, one of them the default
And the other has never been used on an order
When the customer deletes the default address
Then the remaining address becomes the default
