title: Customer can own multiple addresses
status: active
since: 2026-07-30
affects: [customer, orders]
implemented_by: [customer]

A customer may register any number of addresses.

Exactly one address is the default shipping address. The first address added
becomes the default. Deleting the default promotes the most recently used
remaining address; if none has ever been used, the oldest remaining address is
promoted.

A customer with no addresses cannot place an order, which is why this rule
affects `orders` as well as `customer`. See [BR-010](../../../orders/knowledge/rules/BR-010.md).
